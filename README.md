# AI Job Market Skill Analyzer

This project analyzes job postings to identify high-demand skills and predict salary trends.

## Features
- NLP-based skill extraction
- Job market skill analysis
- Salary prediction based on skills
- Streamlit dashboard
- AI career advisor chatbot

## Tech Stack
- Python
- Pandas
- Scikit-learn
- Streamlit

## How to Run
pip install -r requirements.txt
streamlit run app.py
